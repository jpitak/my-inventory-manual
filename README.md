# OGA INTERNATIONAL - My Inventory Manual Website Full Package v8

แพ็กเกจนี้คงรูปแบบหน้าจอของ Website Full Package และเพิ่มรายละเอียดทุกหัวข้อในข้อมูลเว็บไซต์จำนวน 60 หัวข้อ

## รายละเอียดที่เพิ่มในทุกหน้าจอ
- วัตถุประสงค์และคำอธิบายหน้าจอ
- Preconditions
- ส่วนประกอบและปุ่มคำสั่ง
- Process Flow แบบละเอียด
- Field-by-Field
- Business Rules
- Validation Rules
- Use Scenarios
- Error Handling & Troubleshooting
- User Role Matrix
- Audit Trail
- Expected Result / Control Points
- Tips และข้อมูลอ้างอิงที่ค้นพบจากคู่มือต้นฉบับ

## วิธีใช้งาน
1. แตก ZIP
2. เปิด index.html หรือเปิดผ่าน VS Code Live Server
3. ทางเลือก: รัน `python -m http.server 8080` แล้วเปิด localhost:8080

## หมายเหตุ
รายละเอียด Field/Rule ที่เพิ่มเป็นคู่มือการทำงานและ Functional Specification สำหรับตรวจทานกับระบบจริง ควรให้ Process Owner ยืนยันชื่อ Field, Required flag, Permission และสถานะก่อนใช้เป็น Baseline ควบคุมการเปลี่ยนแปลง
